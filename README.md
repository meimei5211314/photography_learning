# 光影手记 · 摄影学习站

面向零基础的中文摄影教程：12 节课程、互动相机实验室、真实拍摄任务与主动回忆卡片。所有风景、相机图示与交互素材均由代码绘制，不需要图片服务、外部字体、账号或构建依赖。

## 打开网页

直接双击项目里的 `index.html` 即可离线使用。建议长期在同一浏览器、同一种打开方式下学习。

也可以在已安装 Node.js 的电脑上，在 PowerShell 中运行：

```powershell
Set-Location 'E:\opencode_workspace\photography_learning'
node server.cjs
```

然后打开 <http://127.0.0.1:4173>。服务只监听本机，按 `Ctrl+C` 停止。若端口占用，可先运行 `$env:PORT=4174` 再启动，然后使用对应新端口。

## 每天 20 分钟的学习方法

1. **先回忆，3 分钟。** 打开记忆卡片，先自行作答，再翻看答案；用“再练 / 模糊 / 掌握”诚实评分。
2. **学一节，8 分钟。** 先看目标与图解，用自己的话说出参数的作用，再回答检查题。
3. **做对比，6 分钟。** 实验室只改一个参数；先预测亮度、虚化或拖影将如何变化，再拖动滑块验证。
4. **复述与迁移，3 分钟。** 不看教材解释“为什么这样设”，写下一个真实场景中的拍摄方案。

每周选两项实战任务，用自己的相机或手机专业模式拍摄。保留参数不同的一组照片；根据验收项比较，写下失败原因与下一次改进。交错练习人像、运动和夜景，避免只会记一组参数。

## 记忆安排与学习进度

- 首次遇到的记忆卡可立即练习。
- “再练”：10 分钟后，回到起始阶段。
- “模糊”：1 天后，保留当前阶段。
- “掌握”：依次安排 1、3、7、14、30 天后；后续维持 30 天间隔。
- 这里的“一天”是连续 24 小时；提醒只在打开网页时计算，不发送系统通知。
- 这个安排用于帮助执行间隔练习，不是适用于每个人的最优记忆曲线；掌握程度仍需要真实拍摄来检验。

课程完成、检查题结果、实战笔记和复习时间保存在当前浏览器的本地存储中。页面提供 JSON 备份导出与恢复。清除浏览器数据、使用隐私模式、换浏览器、换端口或从文件打开切换为 HTTP 打开，都可能得到独立或空的进度；切换前先导出备份。建议将个人备份放进已忽略的 `backups/` 文件夹，不要提交到 Git。

## 教学模型的边界

实验室展示参数变化的趋势；亮度、景深、运动拖影、噪点和颜色是教学示意，不能替代实拍测光或特定镜头标定。焦距实验保持拍摄位置不变，展示取景范围变化；透视主要由拍摄位置决定。提高 ISO 不会让镜头收集更多光；画质还取决于入射光、传感器、处理和显示。实战中的参数是起点，需结合现场光线、主体速度和设备能力调整。

## 结构与维护

```text
index.html       页面入口
styles.css       主界面与响应式样式
app.js           导航、课程、任务、记忆卡与本地进度
data.js          课程、任务、卡片和参考资料
labs.js/css      曝光、构图、焦距与白平衡实验室
learning.js      复习排期和备份数据验证
server.cjs       无依赖的本机静态服务器
tests/           关键计算与状态导入测试
docs/            需求、设计、资料和验证记录
AGENTS.md        后续修改必须遵守的工作流程
```

每次设计或功能修改，先补充 `docs/` 中的需求与实施方案，再改代码、验证并提交 Git。后续可按相机型号补充操作指导、增加任务或扩展课程，但应保留离线能力和已有进度兼容性。

运行自动化检查：

```powershell
node --test tests/*.test.cjs
node --check app.js
node --check labs.js
node --check learning.js
```

本项目在指定目录建立独立 Git 仓库；需求和方案先于实现提交。暂未配置远程仓库或对外发布。教学参考资料见 `docs/03-sources.md` 和站内“知识速查”。
