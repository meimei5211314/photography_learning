# photography_learning · 光影手记

中文交互摄影教程。从真实照片开始，通过对照、参数实验、看图判断、实拍任务与主动回忆掌握摄影。

## 第二版有什么变化

- **真实照片取代装饰性动画**：开放许可的摄影作品保存在 `assets/`，景深与用光提供同场景真实对照，滑动比较细节。
- **五种实验**：实拍对比、曝光取舍、构图、焦距、白平衡。每项明确哪些是实拍、哪些是后期教学处理，不伪造拍摄参数。
- **看图训练**：观察照片后作答，得到证据、错误解释与回课入口；记录最近结果。
- **更准确的学习进度**：区分已阅读、最近自测答对、到期复习；自测答错会进入待巩固状态。
- **保护记忆节奏**：提前自由练习不推进已有到期日；首次和到期卡片正常排期。原有 v1 记录自动迁移到 v2。
- **更舒适的阅读**：课程正文 16px、触控按钮增大、移动布局优化，实验按需更新，没有常驻动画循环。

现有完整内容包括 12 节课程、8 个拍摄任务与 24 张记忆卡。不会上传学习记录或照片。

## 本地打开

双击 `index.html` 可用普通浏览器打开，使用时保留完整项目文件夹。也可启动本地 HTTP 服务：

```powershell
Set-Location 'E:\opencode_workspace\photography_learning'
node server.cjs
```

打开 http://127.0.0.1:4173 。只监听本机；按 Ctrl+C 停止。如端口占用，先运行 `$env:PORT=4174`。

`file://`、HTTP、不同端口和不同浏览器的本地存储可能不互通。长期学习建议固定一种打开方式，定期从“数据备份”导出 JSON。项目不需要 npm 安装、外部图片服务、在线字体或账号。

## 推荐学习方式

1. **先看**：观察课程照片，先描述看见的现象，不急着背参数。
2. **再比**：打开实拍对比，固定看同一细节；解释哪些变量改变了。
3. **做判断**：完成自测和看图训练，读懂证据，不只记正确选项。
4. **去拍**：每次只改变一个变量，按任务标准检查作品并写复盘。
5. **隔天想**：先不看解释主动回忆，再核对。每次十几分钟，长期重复。

卡片掌握后间隔 1、3、7、14、30 天；模糊为 1 天；再练为 10 分钟。一天指连续 24 小时，打开网页时重算，不发送系统通知。这是可执行的练习安排，不是个人遗忘曲线预测，也不承诺几天精通。

## 真实照片与模拟的边界

同场景对照与跨场景例子分别标注。曝光亮度与白平衡处理是基于原片的屏幕模拟，不能恢复不存在的 RAW 信息，也不表示这张照片实际由当前参数拍摄。固定机位的焦距演示是裁切，不能表现走动机位的透视变化。静态照片不会因为调整快门而真实产生主体运动，运动现象请结合实拍样例和拍摄练习理解。

摄影素材作者、出处、许可和处理说明见 `docs/07-media-credits.md` 及站内“知识速查”。**素材许可证只适用于对应图片**，不自动赋予整个项目相同许可。保留署名与许可证链接后再分发；CC BY-SA 图片衍生内容继续按相应许可分享。

## 维护与验证

每次设计前先更新需求，再写方案，然后修改代码、验证、提交 Git。当前需求见 `docs/05-v2-requirements.md`，方案见 `docs/06-v2-plan.md`。不覆盖用户记录；存储格式异常时保留原始内容，允许导出以便恢复。

```powershell
node --test --test-isolation=none tests/*.test.cjs
node --check app.js
node --check labs.js
node --check visual-practice.js
```

采用 Node.js 24 验证。个人 JSON 备份建议保存到 Git 忽略的 `backups/` 目录。项目源码推送到 GitHub 不等于网站已部署；本版没有配置云服务或自动公开学习数据。
