# photography_learning · 光影手记

中文交互摄影教程。从真实照片开始，通过对照、参数实验、看图判断、实拍任务与主动回忆掌握摄影。

## 相机与摄影知识体系

现有 **43 节课程、39 个实战任务、86 张记忆卡、6 个场景案例**，每课包含原理、误区、情境自测和实拍步骤。系统审查后补充“准备与现场控制”“控制光线与成片”，并为最初 12 节基础课增加可观察目标、建议先修和直接实拍入口；阶段 10 将练习落实到已确认的两支镜头，阶段 11 提供假设再增加 R7 的双机练习。

相机基础进一步细化为 **8 节参数详解 + 12 个配置主题**。认识相机、曝光、光圈、快门、ISO、对焦、白平衡和拍摄模式均加入数值/选项对照表，讲清屏幕读数、整档与 1/3 档、等亮换算、自动变量及边界。原课程中的实拍步骤和误区同步补充，旧自测、任务检查项和已有记录保持兼容。

## R6 三代与完整拍摄案例

以佳能 **EOS R6 Mark III（R6 三代）** 为操作实例，结合真实摄影素材、互动实验与主动回忆。

- **R6 三代指南**：8 步上手，理解 Av / Tv / M＋自动 ISO、人物眼睛检测与 Servo、快门类型、RAW＋JPEG、回放与 C1–C3。配方说明选择理由和调整条件。
- **详细配置手册**：12 个可直达主题，分别讲操作入口、画质与记录、曝光模式、自动 ISO、测光与补偿、AF、白平衡、驱动与快门、防抖、回放、自定义控制、C1–C3。每项包含选项取舍、具体操作、结果检查、故障排查和逐项恢复；默认控制与自定义后的差异单独说明。
- **R7 / R6 三代逐项对照**：`#camera-compare` 提供14项基础参数、10步初次设置和12个同主题详细配置。每个环节分别显示两机选项、操作、检查、排障与恢复；手机按环节堆叠并标明机型。R7的两拨盘/ISO按钮、独立LOCK、AF/MF开关、回放放大、白平衡入口及C模式与R6区别清楚列出。
- **6 个完整案例**：窗边人像、户外逆光、多人合影、白天街头、夜街人物、三张叙事。每例连接拍摄意图、起点、现场执行、构图、故障诊断、后期与任务记录。
- **进阶构图**：视觉主次、前中后景、边缘与遮挡、留白、机位和组照关系。用实拍与现有构图裁切实验练习。
- **后期学习**：以佳能 DPP 的 RAW 流程为入口，对照 Lightroom 的常用概念；新增原图/调整图交互工作台和后期顺序练习。网页只进行 JPEG 屏幕演示，不解码 CR3。
- **记忆与进度**：每课有自测和两张卡片，区分阅读与答对，继续使用间隔复习。保留所有原课程/任务/卡片 ID、旧任务检查项及 v1/v2 备份。

通用案例保留全画幅 24–105mm 范围与 f/4 示例，按镜头实际可用光圈调整；当前器材请优先使用下面的两镜专题。照片为观察参考，不宣称它们由 R6 三代、这两支镜头或案例参数拍摄。学习记录不会上传。

## 使用现有 RF50 与 RF-S18–150

已确认器材为 **EOS R6 Mark III、RF50mm F1.8 STM、RF-S18-150mm F3.5-6.3 IS STM**。首页“按我的器材练习”或相机指南进入 `#kit`，查看器材事实、视角对照、六种场景起点与四门专属课程。

- **RF50 定焦**：记录全身/半身/头肩构图的实际站位，比较 f/1.8 与收小光圈后的清楚范围；分清 FOCUS/CONTROL 环切换与机身 AF/MF 设置。
- **RF-S18–150 变焦**：绘制 18/35/50/85/150 附近的个人焦段地图，读出各点真实最大光圈和 ISO，不预填中间焦段光圈。分别检查防抖、主体运动和近摄距离。
- **两镜对照**：RF50 全幅记录的 50mm 与 RF-S 50mm 的裁切记录不同；先看日常使用差异，再让两镜处于相同裁切和共同可用光圈做受控比较。
- **出行配合**：先列拍摄任务，再决定是否换镜；换镜后核对裁切、光圈、ISO、AF 和快门，最后整理五张有不同信息的作品。

RF-S18–150 在这台全画幅机身上自动使用约 1.6 倍裁切，视角约对应全画幅 28.8–240mm；镜头的物理焦距仍是 18–150mm。RF50 在全画幅记录时是 50mm 视角，主动设 1.6 裁切才约对应 80mm。裁切不能保留完整传感器的全部记录范围，RAW 也不记录裁切区域外内容；用实际文件宽高核对记录像素。官网依据与具体限制见 `docs/40-owned-kit-sources.md`。这不要求购买其他器材。

## 如果再增加 EOS R7

`#kit/r6-r7` 是**可选方案**，保留 `#kit` 的已确认配置。首页、器材页顶部和搜索“R7 / 双机”均可进入。新增三课与三项独立任务，未拿到 R7 时可以先写分工计划，实际换机与双机文件检查项留待实拍。

- **分工起点**：R6 三代＋RF50 使用全画幅，练人物、弱光与背景关系；R7＋18–150 使用 APS-C 记录，兼顾环境与较远细节。教程也说明 R7＋RF50、R6 三代＋18–150，以及只带一机的适用情境。
- **视角和像素**：R7 上 RF50 的视角约等效全画幅80mm，18–150约28.8–240mm；不重复乘1.6，也不换算曝光f值。普通静止图像采用3:2、L或RAW/C-RAW时，R7为6960×4640（约3230万记录像素）；R6三代全幅为同样尺寸，1.6倍裁切则为4320×2880（约1240万）。较小JPEG尺寸、其他长宽比与导出另行核对。依据见[佳能R7规格](https://cam.start.canon/zh/C005/manual/html/UG-10_Reference_0100.html)和[R6三代规格](https://cam.start.canon/zh/C022/manual/html/UG-11_Reference_0090.html)。相近视角和更多像素都不直接保证成片质量。
- **操作差异**：按机型核对AF/MF、镜头环、曝光拨轮、自动ISO、对焦检测、防抖和快门驱动；R7有机身对焦模式开关，不能照搬R6菜单步骤。
- **完整流程**：拍前对齐时钟与拍摄目的，换机后读参数并试拍；导入时分机身、分卡保存，防止同名覆盖；统一输出尺寸复盘，并验证独立备份。两机各拍不同内容不等于互相备份。

此方案以现有两镜为边界，不把新增机身作为学习前提；原器材四课和已有进度保持原样。课程/器材核验资料分别见 `docs/44-dual-camera-lesson-sources.md` 与 `docs/45-dual-camera-sources.md`。

详细换机设置从首页、R6指南、R6每个配置主题或双机方案进入“R7与R6三代对照”，也可搜索“R7 ISO”“R7 回放”“R7 LOCK”。基础参数连同模式和限制说明，区分有效/记录像素、快门时间/连拍频率、正常/扩展ISO及卡槽/电池兼容性。原R6手册仍可单独阅读，新增对照不更改43课/39任务/86卡或学习进度。资料核验见 `docs/49-r7-foundation-sources.md`、`docs/50-r7-advanced-sources.md`、`docs/51-camera-comparison-sources.md`。

## 推荐学习方式

1. **先看**：观察课程照片，先描述看见的现象，不急着背参数。
2. **再比**：打开实拍对比，固定看同一细节；解释哪些变量改变了。
3. **做判断**：完成自测和看图训练，读懂证据，不只记正确选项。
4. **去拍**：每次只改变一个变量，按任务标准检查作品并写复盘。
5. **隔天想**：先不看解释主动回忆，再核对。每次十几分钟，长期重复。

卡片掌握后间隔 1、3、7、14、30 天；模糊为 1 天；再练为 10 分钟。一天指连续 24 小时，打开网页时重算，不发送系统通知。这是可执行的练习安排，不是个人遗忘曲线预测，也不承诺几天精通。

## 真实照片与模拟的边界

同场景对照与跨场景例子分别标注。曝光亮度与白平衡处理是基于原片的屏幕模拟，不能恢复不存在的 RAW 信息，也不表示这张照片实际由当前参数拍摄。固定机位的焦距演示是裁切，不能表现走动机位的透视变化。静态照片不会因为调整快门而真实产生主体运动，运动现象请结合实拍样例和拍摄练习理解。

摄影素材作者、出处、许可和处理说明见 `docs/07-media-credits.md`、`docs/12-v3-media-credits.md` 及站内“知识速查”。**素材许可证只适用于对应图片**，不自动赋予整个项目相同许可。保留署名与许可证链接后再分发；CC BY-SA 图片衍生内容继续按相应许可分享。

## 维护与验证

每次设计前先更新需求，再写方案，然后修改代码、验证、提交 Git。R7详细配置需求/方案见docs/47–48，依据见docs/49–51，本轮验证见 `docs/52-r7-configuration-verification.md`。可选双机专题保留在docs/42–46，两镜专题在docs/37–41，相机细化在docs/32–36，系统覆盖矩阵在 `docs/28-systematic-audit.md`。不覆盖用户记录；存储格式异常时保留原始内容，允许导出以便恢复。

```powershell
node --test --test-isolation=none tests/*.test.cjs
node --check app.js
node --check labs.js
node --check visual-practice.js
node --check advanced-data.js
node --check guides.js
node --check editing-lab.js
node scripts/build-pages.cjs
```

CI 使用 Node.js 24，本轮本地验证使用 Node.js 25.7.0，详见验证记录。个人 JSON 备份建议保存到 Git 忽略的 `backups/` 目录。main 分支源码推送后通过 GitHub Actions 自动发布到 GitHub Pages，学习数据仍只保存在浏览器。

向 main 提交的 PR 会单独运行只读权限的验证与打包，不调用 Pages 部署。开发时可选运行 `node scripts/check-browser.cjs`；该检查需要测试环境提供 Playwright（可通过 `PLAYWRIGHT_MODULE` 指定模块路径、`BROWSER_EXECUTABLE` 指定 Chromium 路径），不增加站点运行依赖。截图输出到 Git 忽略的 `.validation/browser/`。
