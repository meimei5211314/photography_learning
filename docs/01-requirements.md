# 摄影学习站 · 需求记录

日期：2026-11-13。版本：v1。用户希望从基础到实践学习摄影，最终交付本地网页，目录 E:\opencode_workspace\photography_learning，使用 Git 管理。

## 学习目标
- 能解释光圈、快门、ISO、焦距、对焦、白平衡和光线的作用。
- 能根据人像、运动、夜景、风景选择起始设置并做取舍。
- 能通过观察、预测、操作、反馈和主动回忆巩固知识。

## 必须满足
1. 中文、零基础友好；基础课程、互动实操、真实拍摄练习形成闭环。
2. 图示和动画优先用 SVG、CSS、Canvas 实现，无外部图片或字体依赖。
3. 至少 12 节可阅读课程；每节有核心解释、步骤、易错点、记忆提示、检查题。
4. 曝光实验室联动光圈、快门、ISO；直观看见亮度、景深、运动拖影、噪点的示意变化。
5. 构图、焦距、白平衡等交互；明确教学模型与真实相机的差异。
6. 至少 8 项户外/居家任务，有操作步骤、验收标准、记录与完成状态。
7. 主动回忆卡片、间隔复习、交错练习；进度本地保存，可导入导出。
8. 桌面与手机适配、键盘可用、尊重减少动态效果设置。
9. 每次设计前先记录需求与方案，再改代码；这一规则写入 AGENTS.md。
10. 本地独立 Git 仓库，先提交方案，再提交实现和验证记录。

## 范围与假设
面向普通可调参相机，手机专业模式也可练习；不绑定品牌型号。不需要账号、后台或云部署。第一版不解析 RAW 或 EXIF。模拟图用于理解趋势，不承诺精确复刻真实镜头或传感器。复习计划是可执行的学习安排，不宣称适用于所有人的最优记忆曲线。

## 验收
所有导航可用；课程能完成并保存；实验参数改变会改变画面且重置有效；测验有解释；练习记录刷新保留；记忆卡揭示后可评分并重新排期；导出可恢复；手机无横向溢出；关键计算有自动化测试；Git 工作树干净。
