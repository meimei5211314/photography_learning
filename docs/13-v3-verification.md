## 边界

没有连接实体 EOS R6 Mark III 验证按钮或实拍；机型功能依据官方手册，自定义分配可能不同。本轮浏览器验证使用 HTTP，未重复 file:// 或完整浏览器备份下载/导入流程；迁移与数据保护由自动检查覆盖。后期工作台是 JPEG 显示练习，不具备 CR3 解码、真实高光恢复、局部蒙版、降噪或照片文件导出。教程已介绍这些操作如何在相应软件完成，并明确网页演示的范围。

用户进度只存浏览器，不随代码上传；GitHub 同步为源码更新，不代表另行部署在线服务。
