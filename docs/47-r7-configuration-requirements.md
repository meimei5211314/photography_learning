# R7 基础参数与逐项配置对照需求

用户要求详细补充R7基础参数、操作配置，与EOS R6 Mark III对照说明，便于换机学习与设置。现有双机页仅有7项摘要，R6三代已有12主题详细手册，因此需要同等深度的R7说明及逐段对照。

## 目标与范围

- 新增基础参数对照：画幅/视角/文件像素、镜头适配、ISO范围、快门、连拍条件、AF/IS、显示、卡槽、电池与照片/视频模式边界。每项说明实际影响与条件，不按规格高低直接判成片质量。
- R7按原R6手册12个主题补齐：操作、画质、曝光模式、自动ISO、测光补偿、AF、白平衡、驱动快门、防抖、回放、自定义控制、C1–C3。每项提供选项与理由、至少6步操作、试拍检查、排障和逐项恢复。
- 两机按相同教学环节并列呈现，手机逐段堆叠并重复机型标签。显著讲清控制入口和设置含义不同之处，尤其R7 AF/MF开关、两拨盘、LOCK按钮、回放放大、AF追踪、白平衡和配置复用。
- 提供初次拿起R7的设置顺序和换机核对单，适用于现有RF50与RF-S18–150；每组参数均为有条件练习起点。
- 保留原R6单机手册、双机组合专题、43课程/39任务/86卡及保存记录。配置阅读不自动改变进度；无需确认购买或清空相机才能学习。

## 验收

1. 新入口 `#camera-compare` 与13个主题深链（基础参数＋12配置）可从首页、R6手册、双机页和搜索进入；旧链接继续可用。
2. 12个R7主题与R6主题逐一对应，每主题差异清楚、步骤可执行、试拍可验证、能够恢复。没有编造不存在的R7菜单、第三拨盘或跨机配置导入。
3. 规格与精确功能由对应官方资料核实，保留来源及固件适用说明。标称速度、ISO、防抖、视频与电池限制不写成无条件保证。
4. 新对照页离线可读、手机无页面横向溢出、键盘可达、刷新与历史导航正常；原进度存储字符串和课程契约不变。
5. 完成内容/界面/集成测试、浏览器验证、目视检查、构建与本地小步提交。
