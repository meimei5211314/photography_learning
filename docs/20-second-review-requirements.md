# 第二轮审查与完善需求

日期：2026-11-14。用户要求继续审查补充完善，基于 b75a96c 的本地版本进行。本轮保持 22 课、18 任务、44 卡，优先补足教学可操作性和异常流程。

## 已确认的缺口

1. 新增测光课介绍了直方图，却没有可观察的图表与读图判断练习；仅文字难以区分低调、高调和重要细节丢失。
2. 看图训练只检查素材映射是否存在，真实图片仍在加载、返回 404 或解码失败时也可评分。后期对比任一图片载入就可隐藏整组的错误状态。
3. 保存失败后用户可以导出或载入最新记录，但缺少保留当前草稿的直接重试路径；离开页面前没有未保存内容提示，侧栏仍显示进度已保存。
4. 继续审查键盘与辅助技术交互，修复有明确复现步骤的问题，避免仅为了增加功能而扩展范围。

## 范围与验收

- 新增四情境直方图读图练习，标明原创合成示意与文字等价描述，先作判断再显示解释，连接曝光课和实拍任务。接入实验室、课程相关入口与搜索，支持 file:// 和手机布局。
- 看图必须在所需照片实际可用后才可评分，失败能重试；切题或离开后过期加载事件不能改变新页面。后期对比只有全部必要图片可用时才标为就绪。
- 保存失败可重试当前草稿，冲突时仍禁止覆盖；未保存内容离开时尽可能提醒。成功导入/重载/保存后清除未保存标志，保持旧格式兼容。
- 新增针对缺图、慢图片、损坏图片、恢复加载、保存恢复和键盘操作的行为验证；运行单元测试、实际浏览器检查与构建。记录具体发现、真实结果及无法保证的边界。

保留原素材与许可、学习数据和零运行依赖。本轮只在本地提交，不推送或发布网站。
