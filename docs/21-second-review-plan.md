# 第二轮完善实施方案

## 直方图教学

新增 `histogram.js/css`，接口 `PhotoHistogram.mount(container,id)` / destroy，导出 `scenarios`（id/title/summary）供搜索；路由 `#histogram` 和 `#histogram/<id>`。四种固定原创合成分布：低调、高调、重要高光贴右、已通过试拍确认的亮暗取舍。用 SVG 柱状图与轴名、文字描述解释分布，不从双峰直接推断动态范围、不模拟真实 RAW 或提供虚假的精确 EV 恢复量。添加情境题、反馈和实拍入口，引用佳能官方播放信息和高光警告页。维持内容数量和备份版本不变。

## 图片实际可用性

`visual-practice.js` 增加 loading/ready/error 状态，以实际图片完成且 naturalWidth > 0 为依据；载入前和失败时阻止作答，错误给明确重试路径。加载回调必须属于当前渲染的图片，旧节点和离开页面的回调失效；避免每选一次答案便重新装载图片、丢失就绪状态。扩充单元测试和浏览器拦截请求的检查。

`editing-lab.js` 对全部原图/调整图核对就绪；单图失败持续提示，后续另一个图成功不能掩盖错误。修复时保留调整和顺序练习。

## 保存恢复与集成

根代理负责 app/index/search/README 及集成测试。保存结果驱动未保存标志；只有未保存的用户编辑才触发 beforeunload 提醒。新增“重试保存本页记录”按钮，不绕过 progress-store 的快照/冲突规则；初次读取被拒时先保留原始保护逻辑，不盲目覆盖未知记录。侧栏提示与状态一致。显式载入和导入仍需确认，失败不替换内存。

## 审查与验证

模块分工避免重叠编辑。计划先落地并提交，再实施。新增摄影事实对照佳能原始手册，保存来源说明。新增错误场景的浏览器检查与已有回归共同执行；图表检查 390px 窄屏、键盘操作、file://、来源链接、情境切换清理及搜索。验证发现缺陷先追加本节再修复。最后本地分步提交，构建版本与源码提交匹配。

## 验证发现与修复记录

- 浏览器回归首次在搜索 Escape 检查中失败：Chromium 的非空 `type="search"` 输入框先消耗 Escape 清空查询。测试改为清空查询后按 Escape，并等待原生 dialog 关闭再检查焦点；未因此修改页面行为。完整回归复跑通过。

### 补充审查结果（实施前记录）

- `labs.js` 与后期页具有同样的双图就绪问题，本轮同步修正，不以任一成功 load 掩盖另一张失败。
- 进度冲突状态可能在临时读取异常后变成 unavailable；若存储又回到旧原值，旧草稿可未经明确重载写入。新增独立冲突锁定状态，只有成功读取到显式加载的快照才解除；测试覆盖冲突→读取异常→原值恢复及失败重载。
- 搜索 dialog 没有可访问名称，结果数量没有状态播报。为标题建立 aria-labelledby，计数使用常驻的 role=status 节点并更新文本，避免随着结果列表销毁播报区域。
- 任务筛选、完成/重新练习重绘后焦点丢失。恢复触发控件；若完成操作使当前任务从筛选结果消失，则将焦点送到当前筛选按钮。相机步骤与案例筛选按实际目标恢复焦点。
- 导入备份的文件读取为异步，离开备份页或开始更新导入后旧请求仍可能弹确认。按请求序号与输入元素连接状态丢弃过期读取，提交前重新检查，避免离开页面后发生恢复操作。
- 复习卡揭晓和评分后原按钮被移除，焦点掉到 BODY；揭晓后聚焦首个评分按钮，评分后聚焦下一张揭晓按钮或空队列标题，验证键盘连续复习。
- 任务与复习筛选仅有 active 样式，补 aria-pressed 表达当前选中状态，与已有阶段及案例筛选一致，浏览器验证切换后的状态。
- 集成复核发现新增相机课的观察题针对指定照片，不能统一用旧相机操作图代替。保留每课 mediaId 照片，原创原理示意仍在展开区，核对提示与可见素材一致。
- 知识模块集成发现镜头专题误用 `focal` 作为课程 ID 和原理图类型；现有课程与图类型均为 `lens`，仅实验路由使用 `focal`。修正课程链接与图类型，新增合法图类型检查并运行知识/跨模块链接测试。
- 新增来源测试过窄地假定官方域名都以 `.com` 结尾，误拒已核验的 `global.canon`、`cam.start.canon`。改为明确的官方主机集合，不修改有效来源；重跑知识与来源去重检查。

## 追加知识体系实施

新增 `knowledge-data.js` 扩展原课程数据，阶段 6 为相机控制（sensor-raw、af-tracking、shutter-stabilization、lens-system），阶段 7 为摄影专题（flash-basics、closeup、night-scene、photo-series）。每课不少于五个实质段落、三个误区、四个拍摄步骤、一道情境题、至少两条内部关联；新增 8 任务、16 卡，不改变原 ID 或检查项位置。通过 sources 字段和专门资料文档记录核验依据。复用已署名素材作为观察，不冒称新课参数对应照片 EXIF。

根代理集成阶段筛选、脚本顺序、素材映射、术语速查与搜索，并扩展已有数据/兼容性/浏览器验证到全部课程。新内容拥有独立测试，备份版本维持不变。原有曝光、对焦、焦距、用光和白平衡页添加相关进阶课入口。

相机与摄影内容分为 `knowledge-data.js` 和 `photography-extension.js` 两个独立模块，均先于 media-v3.js 加载以复用其 mediaId 映射。`glossary.js` 提供 16 条术语摘要及关联课程；速查页支持 `#reference/<term-id>` 定位，搜索包含术语与读图情境。术语是相应课程的摘要，事实依据随课程记录，不作为脱离条件的器材参数表。
- Chromium 键盘实测确认相机“下一步”与任务筛选、卡片揭晓在重绘后落到 BODY。相机下一步将焦点移到新步骤标题，分类筛选保留按钮焦点；浏览器回归检查焦点、搜索对话框名称及跳过导航，不以仅存在 tabindex 作为通过。
