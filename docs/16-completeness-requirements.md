# 内容完整性与学习可靠性增强需求

日期：2026-11-14。用户要求：分析项目有哪些内容缺失或不完整，并直接补充增强完善。

## 审查结论

现有 18 课、14 任务、36 卡与 6 案例已覆盖基础、人像、街拍与入门后期。主要缺口不是更多参数口诀，而是现场判断与完成作品的闭环：

1. 测光、曝光补偿、亮度/RGB 直方图与重要高光只零散出现，缺少一次可验证的完整练习。
2. 失焦、景深不足、主体运动和相机抖动的判断分散在各课，没有从症状到验证步骤的统一入口。
3. 风光/长曝光只有任务片段，缺少前后景清晰、稳定支撑、动态范围与运动取舍的专题。
4. 导出只讲概念，未形成像素尺寸、色彩空间、观看检查与独立备份恢复的完整任务。
5. 搜索只覆盖课程，案例和可执行任务不易发现。
6. 进度保存失败可能被成功提示覆盖；多标签页可覆盖其他页面新增记录；发布前缺少 PR 验证。

## 本轮范围

- 新增 4 节“诊断与交付”课程、4 个对应实拍/交付任务、8 张回忆卡，合计 22 课、18 任务、44 卡；不修改原有 ID 与任务检查项顺序。
- 新增现场排障入口：至少 8 类常见问题，每类给出观察证据、验证动作、调整建议、误区及相关课程/任务。
- 看图训练从 6 题补充至至少 12 题，覆盖既有人像、逆光、合影、白天街头、夜街和后期；保留原题 ID。任务提供结构化复盘提示，已有笔记不被覆盖。
- 首页、阶段筛选、搜索、导航和深链接能够找到新增内容。搜索同时覆盖课程、任务、案例和排障。

- CI 在 PR 上执行验证与打包，仅 main 推送/手动运行可以部署。
- 保持零运行依赖、中文体验、file:// 可用、本地素材和原始进度兼容。
