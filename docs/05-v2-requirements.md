# v2 优化需求与问题分析

日期：2026-11-13。用户反馈纯代码动画效果不佳，解除素材技术限制，要求以学习效率和记忆效果为目标自主优化；完成后推送到 https://github.com/meimei5211314/photography_learning.git 。

## 对现版的判断
1. 抽象山景与移动骑行者能说明参数趋势，但不像真实摄影结果，难以迁移到自己的照片；视觉变化主要是色块与拖影。
2. 课程缩略图和正文重复同一示意图，缺少观察真实照片、比较细节的环节。
3. 大部分正文与控件只有 10–13px，低对比辅助文字过多，长时间阅读负担大。
4. 每课单道文字题，点击完成即可算学过；缺乏看图判断与错误定位。
5. 自由提前复习会把到期日推远；答题结果只记录答对，不记录最近错误，复习优先级不够明确。
6. 动画每帧重绘全部背景和噪点；即使并不需要移动也一直请求动画帧，浪费资源。

## 本次需求
- 采用真实、可合法分发的摄影素材，下载到项目以继续支持离线。优先同场景的景深/运动对照；不能把不同照片冒充控制变量实验，不伪造拍摄参数。
- 将图片、对比滑杆、热点解释、可控实验与代码示意结合。区分真实拍摄、后期模拟与示意图。
- 新增看图诊断题和解释反馈，将“读过”“答对”“待复习”分开显示；保留原有学习记录及备份兼容。
- 提升文字可读性、触控大小、图像比例、移动端和减少动态效果体验。
- 所有新增图片保留作者、来源、许可证、改动记录，发布前检查素材路径与归属。
- 先方案后实现；必要测试、实际浏览器验证、Git 提交后推送指定仓库，禁止强推覆盖远端。

## 验收
真实照片在主页、课程与实验中实际呈现；至少一组同场景摄影对比；至少 6 道观察/情境判断题；曝光/构图/焦距/白平衡交互仍可用并标注限制；提前练习不延后已排好的复习；旧备份可导入；图片离线可用、无第三方页面嵌入；仓库推送提交与本地 HEAD 一致。
