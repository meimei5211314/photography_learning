# 摄影专题的事实核验与教学边界

核验日期：2026-11-14。对应 `photography-extension.js` 的阶段 7 四课、四个任务、八张回忆卡，以及 `glossary.js` 的放大倍率、闪光同步、接触表词条。

课程、问题、任务与反馈为原创中文教学设计。下列厂商手册和教学资料用于核实事实，不照搬文中器材购买建议或全部示例参数；课末与全站资料索引保留可点击来源。

## 闪光入门

- [Canon EOS R6 Mark III：闪光摄影设置](https://cam.start.canon/zh/C022/manual/html/UG-04_Shooting_0820.html)：核实 E-TTL 与手动输出的不同、闪光曝光补偿入口，以及快门模式、裁切与同步速度优先等设置对同步条件的影响。课程不把某一快门值写成所有相机的统一上限，也不保证不同品牌灯具与机身能够兼容。
- [Canon Speedlite EL-10：反射闪光](https://cam.start.canon/en/A009/manual/html/UG-02_Advanced_Flash_0060.html)：核实墙顶反射可改变阴影，有色、远处或低反射率表面会改变颜色或减少到达主体的光。只使用通用原理，不把 EL-10 的按钮操作套给所有闪光灯。
- [Canon Speedlite EL-10：高速同步](https://cam.start.canon/en/A009/manual/html/UG-02_Advanced_Flash_0040.html)：核实高速同步用于超过通常同步上限的曝光；快门加快时闪光指数下降，需检查有效距离。课程不把高速同步等同于光量增强。
- [Canon Australia：Daniel Linnet 的 Speedlite 提示](https://www.canon.com.au/get-inspired/flash-speedlite-tips)：仅用其环境光与闪光分别控制的思路。课程明确限制为常规同步、脉冲完整记录、光圈/ISO/输出/距离固定；主体上的环境光仍会随时间改变。

审稿时主动排除了这篇通俗文章的两种过度简化：不能由“无反没有反光镜”推导所有无反都支持很高的普通同步速度；提高 ISO 也不等于灯具本身发出更多光。机型条件以当前官方产品手册为准。窗光加白纸的替代练习只验证反射补光与阴影观察，不验证 TTL、同步或闪光冻结运动。

## 近摄与微距

- [Nikon：放大倍率与最大复制比率](https://www.nikon.co.uk/en_GB/learn-and-explore/magazine/tips-and-tricks/what-is-magnification-or-maximum-reproduction-ratio)：核实 1:1 为传感器上像与实物的尺寸比。裁切和屏幕放大不改变拍摄时的光学倍率；不把针对不同画幅的营销命名写成倍率发生变化。
- [Nikon 官方手册：目标无法自动合焦](https://onlinemanual.nikonimglib.com/faq/en/shooting_issues/af_target_not_in_focus.html)：核实最近对焦距离的起点为相机成像平面，过近时镜头无法合焦，需检查镜头说明并后退。
- [Nikon：使用微距镜头时的工作距离](https://www.nikonusa.com/learn-and-explore/c/tips-and-techniques/easy-macro-photography-with-the-af-s-dx-micro-nikkor-40mm-f-2-8g-lens)：工作距离指镜头前端与主体之间的空间，与成像平面到主体的对焦距离不同。文中镜头数值不作为其他设备的通用要求。
- [Canon RF Lens World：景深](https://files.canon-europe.com/files/webcontent/rf-lens-world/knowledge/depth-of-field/index.html)：核实近摄距离、光圈、焦距和对焦位置对清晰范围的影响。课程的正对/斜拍、工作空间和光路对照是原创练习；不把最大光圈、最小光圈或固定对焦比例作为保证。

词条审查：`magnification` 的 1:1 定义和工作距离区分与上述资料一致。普通镜头、手机可以完成近摄观察，但课程和检查项不要求也不假定达到 1:1；未知倍率记为未知。合成工作流仅介绍边界，网页不提供焦点合成。

## 夜景与低光现场

- [Nikon：夜间摄影的设置与检查](https://www.nikon.co.uk/en_GB/learn-and-explore/magazine/tips-and-tricks/5-exposure-settings-to-try-for-night-time-photography--an-advanced-guide)：核实长曝光需要稳定支撑，暗处可放大手动对焦，静态夜景与移动人物需要不同时间策略。原文包含多种题材的示例数值，课程不将其变成通用最佳参数。
- [Canon：低光摄影提示](https://www.canon-europe.com/get-inspired/tips-and-techniques/low-light-photography/)：用以核对光圈、曝光时间、相机晃动及主体运动的取舍，以及部分设备手持夜景的多张处理方式。不采用“高 ISO 一定没有明显噪点”等宣传表述；ISO 的物理边界继续沿用全站课程。

夜景课以静物/动作/轨迹和暗处对焦为新增重点，不重复把曝光三角与白平衡入门全文再讲一遍。更完整的高光定位引导至测光课程。居家 LED 轨迹是替代观察，不冒充真实交通场景，也不宣称自动模式或计算合成属于严格单变量对照。

## 组照、排序与接触表

- [Canon Australia：用照片讲述食物与旅行故事](https://www.canon.com.au/get-inspired/telling-food-stories-travel-photography-tips)：以人物、制作和环境提供互补信息的摄影师实例，支持“各张承担不同信息作用”的教学方向。本站“环境、动作、细节、结果”四张训练是原创结构，不声称是该摄影师原话或行业固定标准。
- [Adobe Photoshop：创建接触表](https://helpx.adobe.com/photoshop/desktop/app-integrations/create-a-contact-sheet.html)：核实接触表可在单个文档内集中显示多张图像缩略图。本站任务使用一般相册网格同样可完成选片，不依赖 Photoshop 或特定付费软件。

词条审查：`contact-sheet` 描述数字接触表在比较与选片中的用途，并保留放大检查细节的步骤。排序、删重、事实说明、观看者复述与修改是原创教学建议，不宣称可自动给叙事质量打分。人像身份、动机、事件因果必须有依据；安排或重演的练习如实标注。

## 图片、记录与能力边界

| 课程 | 现有素材 | 使用目的与限制 |
| --- | --- | --- |
| flash-basics | light | 观察水果阴影与光质，不把它冒称闪光样片或推断灯位/功率。 |
| closeup | bokeh | 观察清晰范围，不称作已标定的 1:1 微距图。 |
| night-scene | streetNight | 观察静物、动作拖影与冷暖灯光，不补造 EXIF。 |
| photo-series | street | 区分可见环境/人物/动作与未知身份、前因后果，不编造照片故事。 |

复用图片继续沿用 `media.js`、`media-v3.js` 的作者、来源与许可。没有新增远程运行资源或必需器材。四个任务均可保存现有格式的检查项、完成状态和文字反思；它们不上传、分析或编辑用户原片。新增内容只追加独立 ID，不改旧题、旧任务检查项顺序或备份版本。
