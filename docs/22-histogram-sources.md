# 直方图练习：来源、原创图表与判断边界

核对日期：2026-11-14。本轮先读取佳能官方原始说明，再编写本站情境、反馈与实拍步骤。图表和练习均为原创，不复制厂商配图，也不冒充真实拍摄数据。

## 四个情境与原创设计

- `low-key`：深色杯子与桌布，重要纹理仍能分辨。练习判断“偏左”与“重要细节不足”的区别。
- `high-key`：白花瓶与白纸，重要层次保留。练习判断“偏右”与“重要高光丢失”的区别。
- `highlight-clipping`：白衣刺绣纹理在回放中消失，并有相应高光提示、右端堆积。先验证减少曝光的效果，再检查暗部代价；不要求所有反光点都有纹理。
- `high-contrast`：窗外和室内人物两次试拍仍顾此失彼。结论依赖事先说明的试拍与用途，不能仅由双峰或两端堆积推出动态范围不足；下一步尝试调整光线、位置、时间或明确取舍。

每个图由 32 个手工指定的非负数构成，柱高按该图最大值归一化。横轴只表示相对明暗区间，纵轴为示意相对数量；图中没有声称测得的像素总数或精确 EV。不同图的最高柱一样高，不表示两张照片有相同像素数量。图表旁有可见文字描述，SVG 另有标题和说明。

这些分布用于辨别概念，不模拟相机传感器、RAW 解码、相机回放算法、色调曲线或真实曝光变化。本站没有从现有照片计算这些分布，没有宣称能从回放图推算 RAW 可恢复档数。低调、高调与重要区域的选择及实拍步骤属于本站教学设计，不是厂商为所有场景规定的标准曝光。

## 交互与记录

先展示意图、观察和图表，再由学习者选择下一步；提交后展示对应反馈、解释及实拍步骤。使用原生单选框与表单提交，支持键盘作答与重新判断；详情与列表均有独立深链，未知情境回列表。反馈初始不展示。

四个情境均连接已有测光课与 `metering-bracket` 实拍任务，课程、任务与记忆卡数量不增加。判断只在当前页面存在，不写学习进度或备份；实拍结论由学习者在已有任务中记录。使用本地脚本和内联 SVG，图表本身不依赖网络，官方资料链接需要联网。
