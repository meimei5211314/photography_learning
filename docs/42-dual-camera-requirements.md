# 增加 R7 的可选双机教程需求

用户提出：如果在已确认的 EOS R6 Mark III、RF50mm F1.8 STM、RF-S18-150mm F3.5-6.3 IS STM 基础上增加 EOS R7，把这种组合加入教程。

## 目标与范围

- 保留当前单机两镜入口，新增“如果增加 R7”的独立组合入口，不把假设设备标成已购，不要求购买才能完成原课程。
- 说明四种机身/镜头搭配、记录区域、视角、记录像素及比较条件；区分 R7 原生 APS-C 与 R6 III 的 1.6 倍裁切，避免二次乘 1.6。
- 以 R6 III＋RF50、R7＋RF-S18–150 为分工起点，解释反向配镜、只带一机及不同场景的取舍。参数均是有条件的试拍起点。
- 细化换机时实际操作：AF/MF、对焦/控制环、拨轮和曝光、伺服/主体检测、稳定器、快门和驱动、画质与存储；R6 菜单不冒充 R7 菜单。
- 增加三门课程、三项实拍任务、六张卡片，并补充双机时钟、文件夹、机身标识、选片和统一输出比较的流程。
- 不改旧课程身份、自测答案语义、已存任务检查项、进度格式或六条原有学习路径；复用已有观察照片并明确其并非双机实拍对比。

## 验收标准

1. 从首页、原器材页和搜索可到达双机组合；可直接刷新 `#kit/r6-r7`，可回原配置，未知子路径有可用回退。
2. 全站成为 43 课、39 任务、86 卡，新增阶段 11；旧 40 课/36 任务/80 卡的记录能原样恢复，新任务不自动完成。
3. 两机四组合与官方记录尺寸有条件说明；50mm 在 R7 约为全幅80mm视角，18–150在两机对应模式均约28.8–240mm视角，焦距和曝光f值不因此改变。
4. R7 的机身对焦模式开关和镜头环说明由该机官方手册核实，参考资料可追溯；界面提供可执行核对与失败处理。
5. 桌面/手机、键盘、离线/file://、内部链接、搜索、存储兼容和既有异常回归通过；完成构建、目视检查和本地提交。
