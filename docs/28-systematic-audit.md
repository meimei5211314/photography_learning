# 教程全流程覆盖审查

日期：2026-11-14。审查基线为 0f9c3d0，30 课、26 任务、60 卡；依据实际课程段落、任务、操作指南和实验室，不以标题数量代替知识覆盖。

状态含义：“已覆盖”表示本教程已有解释与练习，不等于学习者已掌握；“需细化”表示提到了名词，但条件、步骤或检查证据不足；“缺失”表示未形成可执行教学链路。

## 避免“课程更多、学习重复”的安排

以下相邻任务保留原 ID 和检查项，但在目标路径中区分用途：

- `night-city` 用蓝调静动建立初步直觉；`street-night` 关注夜街人物与现场关系；`night-comparison` 分开验证静物、动作、轨迹和处理模式。学习者按当前问题选做，无需把同一张作品机械勾三次。
- `mini-story` 是基础三张综合练习；`edit-series` 重点在选片和一致处理；`four-frame-story` 重点在信息分工、排序与外部观看反馈。三个任务的“完成证据”不同，不把张数增加本身称作进阶。
- `focal-distance` 学机位与焦距的基本差别；`lens-position-test` 强调规格限制、同机位裁切和移动机位的可重复比较；近摄任务再处理实际工作距离。
- `af-tracking-test` 主要改变一项 AF 设置；`panning-sequence` 先固定可靠对焦，再改变跟随与曝光时间。两者可使用同一同伴与路径，但应分别记下验证问题。

每条新目标路径使用已有课作为先修，给课程顺序、任务和验收问题；阅读完成、自测答对与任务自报完成各有含义。没有实拍作品，不能仅凭浏览完路径就认定掌握。

`curriculum-support.js` 为 12 门基础课补充 `outcomes`、先修课与主要练习，将学习目标写成可观察的判断或操作；课程页在正文前明确“学完应能做什么”。`learning-paths.js` 再把这些能力连成目标路线，避免把路径页做成另一份目录。整合验收时须确认基础课目标在界面可见，而不是只存在数据中。

| 路径 | 基础能力支点 | 练习与验收边界 |
|---|---|---|
| first-session | camera、exposure、aperture、shutter、focus | 准备检查连接清晰度对照，能解释主动变量和失败原因 |
| people-action | exposure、focus、light、portrait | 窗光先练受光，AF 对照先练焦点，追随再练动作表现；分别保存验证问题 |
| landscape-night | exposure、lens、composition | 地景亮暗对照、附件选择、夜景静动各解决不同问题，不重复要求同一张作品 |
| tabletop | aperture、focus、light、whitebalance | 反射控制、近摄距离、闪光控制分别验收；普通窗光不能证明 TTL 或闪光同步 |
| editing-delivery | exposure、whitebalance、sensor-raw、editing-basic | 局部边界、输出颜色、恢复副本各留证据；网页显示调整不能证明真实文件处理 |
| visual-story | composition、workflow、street | 取景走拍提供素材，四张组照验收叙事，选片处理验收一致性 |

## 本轮范围及后续专业方向

本轮增加 6 课、6 任务、12 卡，达到 36 / 32 / 72，并细化现有基础段落。这里覆盖通用静态摄影从准备到交付的学习流程，不宣称穷尽全部摄影学科。

以下是审查后仍然存在的覆盖边界。P1 表示适合作为下一轮独立专题，P2 表示应在学习需求和设备条件明确后安排；均不扩大本轮已固定的 6 课范围。

| 后续专题或能力 | 当前覆盖 | 优先级与补充条件 |
|---|---|---|
| HDR、全景、对焦合成完整实操 | 部分覆盖：已有包围、景深与场景限制的解释，尚无从采集、对齐、去鬼影到边缘检查的完整软件练习 | P1：分别准备可复现原片、真实合成步骤和失败样本，不能把软件功能名当成已学会 |
| 手机计算摄影 | 部分覆盖：任务提供手机替代和固定光圈、自动处理限制，尚无多帧夜景、计算人像、自动镜头切换的系统对照 | P1：明确机型与版本，区分光学采集与处理结果；优先以同场景条件记录验证 |
| 多灯和商业产品精修 | 部分覆盖：有闪光基础与单一主光源反射控制，尚无多灯独立调节、比例、背景分离及完整精修 | P2：需要可控灯具、触发方式与真实多次对照，避免只画灯位图便声称验证 |
| 视频、收音与剪辑 | 未覆盖系统教学 | P2：独立路线处理帧率、快门时间、运动连续性、声音与剪辑，不直接复用静态照片的验收条件 |
| 天文跟踪和深空叠加 | 未覆盖专业流程；已有夜景知识仅能作为曝光先修 | P2：需星空条件、跟踪/叠加流程、暗场与实际数据，普通夜景不能等同深空摄影 |
| 水下、野生动物专业现场 | 未覆盖专业流程；通用动作跟踪只提供有限先修 | P2：设备、环境、物种与现场条件差异大，应另设有条件的实操范围 |
| 胶片冲洗、大画幅、专业印前与展览安装 | 未覆盖完整流程；色彩输出课只提供通用交付基础 | P2：需要真实介质、处理条件或输出服务的约定与样张 |
| 真实照片自动评阅 | 未实现；当前是文字自测、任务自报和人工保留证据 | P2：属于产品能力，不是新增几段教程就能补齐；先定义输入、判断依据、误判边界与人工复核，现阶段不自动判定作品质量或学习掌握 |

本轮不引入上传照片、自动评分、云同步或后台提醒。教学验收依赖学习者保留原片、记录条件、比较证据与复述理由，网站仅组织课程和本地学习记录。未覆盖项不因学习路径页面或课程数量增加而自动变为已覆盖。
