# 按现有器材扩展教程：需求

日期：2026-11-14，基线 343bab3。用户明确拥有 RF50mm F1.8 STM 与 RF-S18-150mm F3.5-6.3 IS STM，并进一步确认机身为 EOS R6 Mark III。

## 学习目标

将现有通用教程落实到这套已确认器材，围绕现有设备建立选镜、站位、曝光、对焦和换镜判断，不以购买其他镜头作为完成练习的前提。

1. 解释两镜在该机身上的记录区域和实际视角：RF50 的全画幅记录与 RF-S18-150 的强制约 1.6 倍裁切不同；焦距本身不变，记录像素需按实际文件核对。
2. RF50：工作距离、背景关系、f/1.8 并非所有人像的默认答案、不同光圈的清楚范围、镜头与机身防抖分工、对焦/控制环使用。
3. RF-S18-150：18/35/50/85/150 附近的焦段分工、可变最大光圈、ISO/快门联动、防抖与主体动作、近摄限制；不编造中间焦段最大光圈或将特殊 MF 能力当作所有焦段 AF 能力。
4. 两镜比较要控制记录区域和构图条件；在同机位、匹配视角、各自实用能力三种问题中分别记录。换镜之后检查裁切和曝光，而非只换镜头就继续拍。
5. 新增四门课程、四个实拍任务、八张记忆卡；保留旧课程身份、自测、检查项、笔记及备份格式。器材入口汇总事实与起步选择，深度内容进入正式课程，避免复制两套教材。
