## 必须保留的比较条件

1. **先分记录区域。** A 组用 RF50 全幅与 RF-S 约 50mm 自动 1.6 裁切，观察正常使用时的取景差别。此组不能直接证明同视角画质或虚化的胜负。
2. **B 组主动匹配。** RF50 也设为 1.6 裁切，或从其全幅原片创建明确记录像素、范围和方法的裁切副本。保留原图。读变焦当时最大光圈后选择共同可用光圈，f/8 仅为核对后的例子，绝不预填变焦 50mm 处最大光圈。
3. **从实际文件读取。** 变焦环的 50 刻度附近不保证记录值精确等于 50mm；检查实际焦距、文件宽高、机位、对焦目标、白平衡与处理。近距离成像及镜头校正可造成少量范围差别，不要求边缘逐像素重合，也不能暗中移动相机“补齐”。
4. **C 组说明变量。** 各用需要的光圈、固定满足动作的快门、记录实际 ISO，回答实用效果问题。这并未隔离光圈等变量，不能称为实验室 MTF 测量或镜头锐度排名。
5. **同构图另记位置。** 用不同焦段、不同记录区域保持主体相近占幅时，要记录相机到主体的距离；背景关系变化不能只归给镜头。完成后检查 RF50 的手动裁切，需全幅时主动恢复并试拍。

1.6 倍换算只用于视角参照：18×1.6=28.8（约 29）、35×1.6=56、50×1.6=80、85×1.6=136、150×1.6=240mm。实际焦距未变，不为曝光设置把 f 数乘 1.6。课程不以假定的传感器总像素计算并宣称实际文件像素，要求读取拍摄结果。

## 练习参数与媒体边界

- RF50 的 f/1.8、f/2.8、f/4 是比较选择，不把前两者误说成正好相差一整档。1/250 秒只是较静止人物或观察练习的起点；动作、光线和高光边界决定是否调整。
- 变焦改变了画面亮暗分布，自动 ISO 差异不一定全来自光圈。课程要求固定一处焦段另做收光圈对照。中间焦段最大 f 值和真实 ISO 由使用者填写。
- 普通 AF 近摄是基础任务；特殊 MF 中央近摄为有条件的扩展，不要求新手必须进入专用范围。未做的部分要明确未验证，不能用屏幕放大或裁切声称光学倍率。
- 复用 `portrait`、`landscape`、`dof`、`street` 四个既有署名素材，其来源与许可沿用媒体数据。它们仅用于观察，不是本套机身镜头的实测对照，也不提供推测 EXIF。
- 本轮完成官方资料核验及代码检查，未操作用户的实体相机、未拍摄镜头性能样本。实际全站测试范围由 docs/41 记录；用户实拍结果应在任务中逐项保存。
