## 发现与修正

均先在 docs/33 记录，再修改和验证：

1. 手机光圈课的长整档链使页面横向溢出；定位到正文而非表格，添加正文长串换行后重新遍历通过。
2. 快门秒号示例去掉可见转义残留，运行时正文检查通过。
3. ISO 表改为“标称 ISO 数值比”，说明它不是屏幕亮度、JPEG 像素或噪声的倍数；保留曝光档差和两种实拍对照。
4. 光圈阶梯测试考虑标称 f 数取整，避免将正确的“约一档”误报为失败。
